# Changelog — AURORE PARIS

All notable changes to this project are documented in this release record.

## [v1.1.0] - 2026-10-05
### Added
- **Three.js 3D Flacon Atelier**: Real-time WebGL interactive 3D Baccarat crystal flacon viewer with glass transmission refraction, internal amber elixir core, floating 24K gold suspension particles, and guilloché gold cap.
- **Flacon Finish Selector**: Live shader finish toggles (Amber & 24K Gold, Noir Profond, Baccarat Clear).
- **2.5D Holographic Depth Tilt**: Vault product cards respond dynamically with 3D matrix perspective and subtle optical shift on pointer movement.
- **Enhanced Video Poster Preload**: Zero-blackout hero loading with high-resolution studio poster fallback and immediate initial frame decoding.
- **3D Atelier Triggers**: Interactive inspection access directly from Chapter 01 (Vessel) and Chapter 02 (Crystal Anatomy).

## [v1.0.0] - 2026-10-04
### Added
- Complete luxury client website frontend (HTML5, CSS3, Vanilla ES6+ JavaScript).
- Deep dark luxury design system with custom CSS variables, responsive typography, and glassmorphism.

- Accessible Cookie Consent Banner with LocalStorage state persistence.

- Custom branded `404.html` error page.
- Technical SEO: `sitemap.xml`, `robots.txt`, canonical tags, Open Graph and Twitter Cards.

- Production `nginx.conf` with OWASP security headers, gzip compression, and caching policies.
- Automated CI pipeline `.github/workflows/ci.yml`.
- Complete documentation suite (`README.md`, `DEPLOYMENT.md`, `SECURITY.md`, `CLIENT_HANDOVER.md`, `CLIENT_CONFIGURATION_REQUIRED.md`).
